# Student Management System

مشروع مقرر BWP501، برمجة الويب 2. موقع PHP وMySQL لتسجيل الطلاب وإدارة بياناتهم.

رابط الموقع: https://studentrecords-system.infinityfreeapp.com/

## متطلبات التشغيل

- PHP 8.2 أو أحدث مع PDO MySQL وmbstring وfileinfo وsession.
- MySQL 8 أو MariaDB متوافق، وخادم Apache عند النشر.
- صلاحية كتابة PHP في `website/storage/photos`.
- يفضل أن تكون `upload_max_filesize=4M` و`post_max_size=8M`. يقبل التطبيق نفسه صورة حتى 2 ميغابايت فقط.

## تشغيل محلي باستخدام XAMPP أو WAMP أو Laragon

1. شغّل Apache وMySQL.
2. افتح phpMyAdmin واستورد `database/schema.sql` لإنشاء قاعدة `student_registration_system` وجدولي `users` و`students`. عند استخدام قاعدة موجودة اختر القاعدة ثم استورد `database/tables.sql`.
3. انسخ `website/config.example.php` إلى `website/config.local.php` وعدّل المضيف والمنفذ واسم القاعدة والمستخدم وكلمة المرور وفق إعدادك المحلي.
4. ضع محتويات `website` في مجلد موقع داخل `htdocs` أو `www`، ثم افتح الموقع عبر عنوان خادمك المحلي. لا تفتح ملف HTML مباشرة باستخدام `file://`؛ لأن الحسابات تحتاج PHP وجلسة خادم.

## النشر على InfinityFree

1. أنشئ حساب الاستضافة والنطاق، ثم قاعدة MySQL من قسم MySQL Databases في لوحة التحكم.
2. افتح phpMyAdmin واختر قاعدة الاستضافة. استورد `database/tables.sql` فقط؛ لأن الاستضافة تختار اسم القاعدة المسبوق بمعرّف حسابك. لا تستورد `schema.sql` هناك.
3. ارفع محتويات `website` داخل `htdocs` الخاص بالنطاق. تأكد من رفع `.htaccess` الرئيسي وملفات `.htaccess` داخل `src` و`templates` و`storage`، ومن وجود `storage/photos`.
4. على الاستضافة انسخ `config.example.php` إلى `config.local.php`. أدخل اسم مضيف MySQL واسم القاعدة واسم المستخدم وكلمة المرور التي تظهر في لوحة حسابك. مضيف MySQL في InfinityFree ليس `localhost`؛ انقل القيمة كما تظهر في اللوحة.
5. افتح الموقع من المتصفح واختبر إنشاء حساب وتسجيل الدخول وإضافة سجل تجريبي بصورة وتعديله وحذفه. افتح `/config.example.php` و`/src/Database.php` و`/storage/photos/` وتأكد من منع الوصول المباشر. إذا ظهرت الملفات أو قائمة المجلد بدل المنع، لا تستخدم بيانات حقيقية قبل إصلاح إعداد الخادم.
الموقع منشور على https://studentrecords-system.infinityfreeapp.com/

## طريقة الاستخدام

1. اختر «إنشاء حساب»، وأدخل اسم مستخدم وبريدًا صحيحًا وكلمة مرور وتأكيدها. لا يوجد حساب افتراضي أو كلمة مرور جاهزة في قاعدة التسليم.
2. سجل الدخول بالاسم أو البريد. تعرض «نظرة عامة» عدد الطلاب وإضافات اليوم والسجلات التي لها صور.
3. اختر «تسجيل طالب». الحقول النصية الأربعة مطلوبة، والصورة اختيارية. تظهر معاينة للبطاقة، وتظهر أخطاء التحقق بجوار الحقول أثناء الكتابة.
4. في «دليل الطلاب» ابحث بالاسم أو البريد أو الهاتف، واختر الترتيب ثم اضغط «بحث». تعرض الصفحة عشرة سجلات وتحتفظ روابط «السابق» و«التالي» بشرط البحث والترتيب.
5. اختر «تعديل» لتحديث البيانات. ترك حقل الصورة فارغًا يحافظ على الصورة الحالية. يمكنك رفع بديلة أو تحديد «إزالة الصورة الحالية».
6. اختر «حذف» لفتح مراجعة مستقلة. لا يحدث الحذف إلا بعد زر «تأكيد حذف الطالب»؛ «الاحتفاظ بالسجل» يلغي العملية.
7. استخدم «تسجيل الخروج» لإنهاء الجلسة. عند تعطيل JavaScript توجد روابط إلى نماذج PHP المباشرة في صفحتي الدخول والتسجيل، وتستمر عمليات الحفظ والتحقق على الخادم.

كل الحسابات المسجّلة تتعامل مع دليل مشترك بحسب نطاق هذا المشروع. لا يحتوي على صلاحيات مدير أو عزل سجلات حسب المستخدم.

## شرح مختصر للتنفيذ

الحسابات تستخدم `password_hash` عند التسجيل و`password_verify` عند الدخول، مع تجديد معرّف الجلسة. تمنع الصفحات الداخلية العمل قبل تسجيل الدخول. تحمل عمليات التغيير رمز CSRF وتُرسل باستخدام POST. تقييد محاولات الدخول موجود داخل الجلسة لمدة خمس دقائق بعد ثماني محاولات فاشلة؛ ليس حظرًا عامًا حسب IP.

تستخدم قاعدة البيانات PDO واستعلامات محضرة، وتُهَرَّب النصوص عند إدراجها في HTML. يُختار ترتيب SQL من قائمة ثابتة. يُنفذ البحث باستخدام LIKE على ثلاثة أعمدة، مع تهريب `%` و`_` لكي يعاملهما البحث أحرفًا فعلية. ينفذ COUNT أولًا ثم LIMIT وOFFSET لجلب الصفحة المطلوبة.

يرسل JavaScript الحقول النصية ورمز CSRF إلى `validate_student.php` بعد مهلة 350 ميلي ثانية، ويلغي الطلب السابق عند إرسال طلب أحدث. يعود JSON بالأخطاء. يتشارك هذا المسار ومسار الحفظ قواعد `StudentRules`؛ تعطل AJAX لا يمنع التحقق على الخادم.

تفحص الصور بالحجم وMIME باستخدام fileinfo وبنية الصورة باستخدام `getimagesize`. تُرفض الملفات التنفيذية والصيغ غير المسموحة، ويولد الخادم اسمًا عشوائيًا بدل اسم الملف المرسل. يستخدم `move_uploaded_file` لحفظ الصورة، ويحفظ مرجعها في الجدول. تُحذف الصورة القديمة بعد نجاح التعديل، وتُحذف صورة السجل بعد حذف السجل.

## التحقق والحدود

شملت الاختبارات المحلية التسجيل والدخول والإضافة والتعديل والحذف والبحث ورفع الصور والتحقق من الحقول. بيانات اللقطات تجريبية. القاعدة المرفقة فارغة ولا تحتوي حسابا افتراضيا. لا توجد خدمة استعادة كلمة المرور.
